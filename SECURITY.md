# Security policy / Політика безпеки

- Облікові дані Wi-Fi, OTA та Telegram тримайте **тільки локально** у `include/secrets.h` і `ota_password.txt`. В Git слід зберігати лише `include/secrets.example.h` із вигаданими заповнювачами.
- Якщо ключ, токен або пароль випадково потрапив до Git — **змініть/відкличте його**, оскільки видалення із поточного файлу не прибирає секрет з історії комітів.
- Перед майбутнім відкриттям репозиторію перевірте історію Git, Pull Requests, вкладення, зовнішні посилання й журнали збірок. Автоматичне сканування за шаблонами не дає абсолютної гарантії.
- Не публікуйте експлуатаційні подробиці вразливостей разом із секретами. Якщо в GitHub увімкнено Private Vulnerability Reporting, скористайтеся ним, інакше зв'яжіться з власником приватним каналом.
- У системи немає апаратного захисту батареї; програмні сповіщення не гарантують відключення небезпечного навантаження. Докладніше: [SAFETY](docs/SAFETY.md).
