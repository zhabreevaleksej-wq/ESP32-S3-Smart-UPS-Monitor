# Contributing / Внесок у проєкт

ESP32-S3 Smart UPS Monitor — експериментальний технічний проєкт. Перш ніж пропонувати зміни, прочитайте [README](README.md), [SAFETY](docs/SAFETY.md) та [правила спільноти](CODE_OF_CONDUCT.md).

- Нові функції розробляйте в окремих гілках `feature/...`; документацію — у `docs/...`.
- Для Pull Request опишіть мету, змінені файли, реальні випробування, відомі обмеження та результат `pio run -e esp32s3`.
- Ніколи не додавайте `include/secrets.h`, `ota_password.txt`, паролі Wi-Fi, Telegram-токени чи приватні журнали.
- Не змінюйте теги перевірених релізів `v3.8` і `v3.9`. Відокремлюйте збірку від фактичного тестування на пристрої.
- Для змін графіка відключень перевіряйте формат, часовий пояс, регіон, чергу, актуальність дати та доступність джерела.
- У відкритих issue не публікуйте реальні секрети або інформацію, що створює ризик для обладнання.
