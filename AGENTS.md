# ESP32-S3 Smart Mini-UPS Monitor

## 1. Призначення проєкту

Розумний монітор резервного живлення для Wi-Fi роутера та оптичного термінала ONU на базі ESP32-S3.

Основна мета — моніторинг стану літієвого акумулятора, напруги окремих комірок, струму, потужності та стану системи через вебінтерфейс.

## 2. Обладнання

- ESP32-S3-DevKitC-1.
- Модуль автоматичного перемикання живлення YX850.
- Мережевий адаптер 12 В.
- Основний акумулятор Li-ion 3S.
- Можливе використання 4S.
- Акумулятор 6S є резервним, але штатно не використовується.
- INA219 — поточний датчик напруги, струму та потужності. Наразі фізично відключений.
- INA226 — замовлений для подальшої заміни INA219.
- Три понижувальні перетворювачі LM2596.
- Зарядний пристрій ToolkitRC M7 із блоком живлення ADP100 100 Вт.

## 3. Схема живлення

Адаптер 12 В підключений до DC+/DC− модуля YX850.

Акумулятор підключений до BAT+/BAT− модуля YX850.

Силовий шлях:

YX850 OUT+ → INA219 VIN+ → INA219 VIN− → вузол розподілу живлення.

Від вузла розподілу живляться:

- LM2596 №1 — 9 В для роутера.
- LM2596 №2 — налаштований на 12 В для ONU (номінальне споживання ONU 12 В / 0,5 А).
- LM2596 №3 — 5 В для ESP32-S3.

Усі GND об'єднані.

ESP32 живиться через контакт 5V від LM2596 №3.

Враховувати, що LM2596 є понижувальним перетворювачем і не може підтримувати стабільні 12 В на виході, якщо вхідна напруга недостатня.

Датчик струму після YX850 вимірює загальне споживання навантаження, а не окремо струм акумулятора.

## 4. GPIO та підключення

I²C:

- SDA — GPIO15.
- SCL — GPIO16.
- Живлення INA219 — 3,3 В.
- GND — спільний.

Балансувальний роз'єм 6S через резистивні дільники:

- GND — спільний GND.
- B1 — GPIO4.
- B2 — GPIO5.
- B3 — GPIO6.
- B4 — GPIO7.
- B5 — GPIO8.
- B6 — GPIO9.

B1–B6 вимірюють накопичувальні напруги від загального мінуса батареї. Напруги окремих комірок визначаються різницею сусідніх вимірювань.

B4–B6 ще потребують калібрування.

GPIO2 раніше резервувався для MOSFET, але наразі MOSFET не використовується.

Не змінювати GPIO, коефіцієнти дільників або калібрування без погодження.

## 5. Обмеження апаратної частини

- OLED та інші дисплеї не використовуються.
- Датчики температури не використовуються.
- Зовнішні MOSFET для відключення навантаження наразі не використовуються.
- BMS у поточній конструкції немає за рішенням власника.
- Автоматичне заряджання не реалізується.
- Акумулятори заряджаються вручну зовнішнім зарядним пристроєм ToolkitRC M7.
- Програмні попередження не є заміною апаратного захисту акумулятора.
- Не додавати нові апаратні компоненти без погодження з власником.

## 7. Поточний функціонал v3.5

- Автоматичне визначення кількості комірок 1S–6S.
- Вимірювання напруги акумулятора та окремих комірок.
- Визначення розбалансу.
- Приблизна оцінка заряду.
- Вимірювання напруги шини, струму та потужності через INA219.
- Україномовний вебінтерфейс.
- JSON API /api/data.
- Графіки останніх 60 вимірювань.
- Попередження про стан акумулятора.
- Автоматичне перепідключення Wi-Fi.
- OTA-оновлення.
- RSSI та uptime.
- Причина перезапуску ESP32.
- Вільна heap-пам'ять.
- Версія прошивки.
- Дата та час компіляції.

Період опитування датчиків — 3 секунди.

Прошивка v3.5 успішно скомпільована, завантажена через OTA та перевірена на ESP32. Тривала перевірка стабільності ще не завершена.

Останній зафіксований показник вільної RAM — приблизно 243,7 КіБ.

## 10. Подальший розвиток

Наступний запланований етап — v3.6 INA226 Power Monitoring.

Після отримання INA226:

1. Перевірити фактичний модуль, його контакти та номінал шунта.
2. Створити feature/ina226 від develop.
3. Підібрати сумісну бібліотеку INA226.
4. Замінити програмну підтримку INA219 на INA226.
5. Зберегти існуючі функції v3.5 та вебінтерфейс.
6. Налаштувати вимірювання напруги, струму та потужності.
7. Перевірити компіляцію.
8. Після дозволу власника виконати OTA та перевірити показники мультиметром.

INA226 ще не отриманий, тому не починати його інтеграцію без окремого завдання.

Telegram-бот відкладений на майбутнє. Не використовувати зовнішні онлайн-джерела графіків відключення електроенергії.
