# Правила спільноти / Code of Conduct

**Основна мова проєкту — українська.** Запитання, звіти про помилки та технічні пропозиції українською або англійською вітаються. Переклад інтерфейсу іншими мовами не є обов'язковою умовою участі.

## Принципи спілкування / Community standards

- Обговорюйте технічні рішення, результати вимірювань та код, а не особистість автора чи учасників.
- Не допускаються образи, погрози, переслідування, спам або дискримінаційні висловлювання, зокрема щодо мови, громадянства чи походження.
- Конструктивна критика реалізації, безпеки та документації вітається, навіть якщо думки не збігаються.
- Не публікуйте реальні паролі, Telegram-токени, домашні адреси, особисті повідомлення та інші приватні дані.
- Дотримуйтеся норм GitHub і вимог безпечної роботи з літієвими акумуляторами. Не рекомендуйте небезпечні зміни як гарантовано безпечні без перевірки.

## Модерація / Moderation

Власник репозиторію може приховувати або видаляти коментарі, закривати обговорення й блокувати користувачів у межах доступних інструментів GitHub. Рішення ґрунтуються на поведінці в обговоренні, а не на національності учасника. Технічні запитання та добросовісні заперечення не є порушенням.

## Повідомлення про порушення / Reporting

Скористайтеся інструментами Report/Block на GitHub, якщо повідомлення містить переслідування чи образи. Не публікуйте додаткові персональні дані у відкритому issue. Про вразливості безпеки повідомляйте згідно з [SECURITY.md](SECURITY.md).
